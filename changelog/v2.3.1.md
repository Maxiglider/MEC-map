# MEC v2.3.1

Changes since v2.3.

## `-smic` and mec-smic-loader

**This version needs mec-smic-loader 2.3.** An older loader given a `-smic` of this version would set every terrain height of the map to 0.

- **Terrain heights no longer drift on ramps.** Each `-smic` and load moved some ramp tilepoints by 32 or 64 more, growing into spikes after a few round trips. `-smic` no longer exports the heights, cliffs and ramps of the map: mec-smic-loader keeps them from the map it loads into, and only adds the height changes made in the game with `-terrainHeight` (`-cancel` taking them back). Ramps, cliffs and water are now kept exactly as they are in the World Editor.
- mec-smic-loader 2.3 always needs the map to load into, which the shortcut created by dropping a map on it already gives. It refuses a `-smic` made by an older MEC version (make it again with this one), and a `-smic` made in a map of other dimensions.
- `-smic <name> withoutTerrain` can now be given to mec-smic-loader: the terrain and minimap of the map are kept as they are.
- `-smic` no longer desyncs multiplayer games.
- `-smic` no longer shows again the destructables a map had hidden.

## Afk

- Chat messages, commands included, and camera moves now count as activity: a player who is there is no longer marked afk just because their hero did not move.

## Fixes

- `-toggle` now passes "on" or "off" to the command it runs, not "1" or "0".

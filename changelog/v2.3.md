# MEC v2.3

Changes since v2.2.

## Slide

- **Async slide**: each player's own machine now moves their sliding hero, so steering reacts without network delay. Choose with `-slideMode`: `asyncClicks` (default, the hero turns towards the right click), `async` (follows the mouse) or `legacy`. An optional quest explains it.
- **Slide speed control** (`-slideSpeedControl on/off`): hold the right click to speed up, the left click to slow down, within bounds set by the maker. Hints are written under the start zone. This new feature is disabled by default and can be enabled by the mapper.
- **Physical turn**: sliding heroes turn at their maximum rotation speed, with acceleration and braking, and turns are sharper. Inertia can be set per slide terrain or forced per hero. The old behaviour stays available with `-legacySlideInertia`.
- The vToto slide logic (terrain read per tile) is now on by default.

## Contacts

- MEC now detects every contact between heroes and monsters itself, instead of using the Warcraft III immolation. Immolation radiuses keep their meaning (the size of a monster). It permits monsters to kill heroes sliding async, and increases game performances.
- Mortars hurt heroes again, with the area damage set in the object editor. `gameData.mortarAreaShift` adjusts the mortar areas (not to be used in most cases).

## New features

- **Doors and keys**: one key per door, as in the old Polar Escape maps. Doors can also have no key and be opened by a map trigger. A carried key shows in the hero's hand. A door kills through a rect that follows its orientation, measured from its pathing if no dimensions are given.
- **Terrain saves**: save the whole terrain or a zone, per level or global; load, unload, update, rename them. Events can apply/unapply a save automatically at level start/end, when a monster is touched (switches) or dies, with delay, period and duration.
- **Burn terrains** (`-newBurn`): a death terrain that spreads over the slide tiles of the level it touches.
- **Visibility per tile**: paint visible, masked or blinking (periodic) tiles per level with `-createVisibility`. Masked tiles can hide what a lower level reveals. Old visibility rectangles still work and can be converted with `-convertVisibilities`.
- Paint bucket: `-createTerrain <terrainLabel> fill`.
- Monster types: own color, periodic idle animation/effect, radius of sight (to light a dark level).
- Casters: blind mode (shoot straight along their angle) and fans of projectiles. A caster wears the color of its monster type.
- Portal mobs can be one-way.
- A monster spawn can keep running during the next level (`keepAliveForNextLevel`).
- Coop/solo choice at start can be turned off (`-coopModeChoice`), in this case solo mode is automatically chosen ; coop can be switched by admins during a game (`-enableCoop`).
- Heroes can be kept from appearing on their own at game start (`-autoSpawnHeroes`), so that a map can play its own intro.
- Heroes get their full life back at each checkpoint.
- AFK heroes are killed after 8 s instead of 4 s. Chat messages (commands included), camera moves (except a camera locked on the hero) and moving the cursor during an async slide now count as activity.
- Heroes' selection circles stay hidden after a cinematic (no more need to use `MEC_core.resetRoundScores()` in a custom trigger).
- The duration of the life bonus message can be set.
- `-<command> /?` shows the help of a command.
- `-toggle <command>` runs a command with a boolean that switches each time.
- Removing a door, key, caster or monster type still in use requires `--force`.
- `-debugRegions` stays on from one level to the next and, with `monsters`, draws the doors' kill rects.
- `-displayMonsterSpawns` shows the spawns kept alive from the previous level.
- `-debugCollisions` also shows casters, their shots and spawned monsters. Collision landmarks no longer cost anything in games where nobody uses it, and much less when it is on.

## Fixes

- Several desync causes removed: shared logic no longer depends on handle ids or on anything computed by one machine only.
- `-smic`: the terrain order no longer breaks on a terrain array with holes (in case of the use of `-removeTerrain` command.
- Multiple patrols no longer stop for good at one of their points.
- A portal now keeps the hero's height and fall.
- A monster whose unit is a hero now belongs to the neutral enemy to prevent the apparition of the hero icon on the owner's screen.
- 0 lives is accepted as a value (at start and earned by a level).
- A hidden monster no longer shows a collision landmark.
- Closing the coop/solo dialog no longer gives back control of the camera during a cinematic.
- A make click on a unit, an item or a destructable takes the right position.
- Changing a monster type's immolation no longer recreates its units.

## Renamed / removed

- `-createKey`, `-deleteKey`, `-deleteKeysBetweenPoints` (meteors) become `-createMeteor` (`crmr`), `-deleteMeteor` (`delmr`), `-deleteMeteorsBetweenPoints` (`delmrbp`).
- `-saveTerrain`, `-loadTerrain`, `-deleteTerrainSave` move from Admin to Make, with new arguments.

## MEC_core API

- `getLives()`
- `spawnHeroes()`: makes the heroes appear when `-autoSpawnHeroes` is off.
- `setAfkPaused(boolean)`, `isAfkPaused()`: pause the AFK system (during cinematics).
- `setSlideSpeedControl`, `setSlideSpeedControlMax`, `setSlideSpeedControlMin`, `setSlideSpeedControlAcceleration`, `setSlideSpeedControlBraking`
- `onGameWinning`: a callback returning `false` cancels MEC's end of the game.

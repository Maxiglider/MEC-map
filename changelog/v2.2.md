# MEC v2.2

Changes since v2.1c.

## New features

- **Hero collision size**: heroes now have a base collision size (25 by default on new maps, by steps of 5). On old maps, `-patchImmo` raises it and lowers every monster immolation to keep the same gameplay.
- **Collision landmarks**: hero collisions and monster immolations can be shown as circles (`-debugCollisions`).
- **Kill rects**: an immobile monster type can kill through a rectangle instead of a circle (doors, walls…).
- **Life bonus monsters**: a monster type can give lives to the team instead of killing, once the hero has survived for a set time after touching it.
- **TP for end**: optional rectangle per level that teleports heroes to the center of the level's end.
- **MEC Regions**: new zone shapes (horizontal rect, rotated rect, line, circle, parallelogram, trapeze), used by monster spawns.
- Each change in the number of lives now shows the new count.
- Grid: smoother lines, several colors, follows terrain height (grids 1 and 2). `-grid` is now an All command.
- Debug lines are thinner and colored; Make clicks leave a small cross in the player's color instead of a dummy unit.
- `-getTerrainInfo` also shows the MEC properties of the clicked terrain.
- `-getMonsterInfo` works on spawned monsters and shows their monster spawn.
- `-smic` also saves the playable area and camera bounds, so mec-smic-loader can generate a minimap.

## Monster spawns

- Rewritten on MEC Regions. Directions `leftToRight`, `upToDown`… are replaced by zones: `up`, `down`, `left`, `right`, `line` (2 clicks), `rect` (3 clicks), `parallelogram` (3 clicks), `trapeze` (4 clicks). Old maps are converted automatically.
- Spawned monsters can move in a random direction instead of straight.
- Dead zones: in these zones, spawned monsters are hidden and harmless.
- `fixedSpawnOffset` accepts `auto`.
- Spawned monsters face where they go and move without delay after spawning.
- Long moves are split into short orders so that monsters keep a straight line.

## Fixes

- `-smic`: several desync causes removed, much less likely to desync in multiplayer; backslashes no longer multiply on each save; fixed backslashes doubled by the WC3 engine (Preload).
- Spawns, MEC Regions and long moves no longer depend on handle ids (desyncs).
- `-debugCollisions` no longer desyncs; its circle is removed with the hero.
- Mortars now hurt heroes standing on a place where the terrain has a height difference from mortar's location.
- Casters' shots now trigger the kill effect when they kill a hero.
- The kill effect of a monster is destroyed at once instead of after 3 seconds.
- `-verticalSymmetryTerrain` / `-horizontalSymmetryTerrain` respect the selected zone exactly.
- Monsters reveal the map around them for a shorter time.
- Kill rects were wrong on angles multiple of 90.
- Monster spawns: monsters were only made for the enemy player; several spawn bugs and memory leaks fixed.
- Right-clicking a meteor on the ground no longer shows an error.
- `-leaderboard` now answers the player who typed it.
- Singular/plural of lives messages.
- Terrain palette and interface display bugs.
- MEC_core hooks could still run after being destroyed, and received the hook as first argument.
- Release: no more doubled `%` in `MEC_core.lua` (recent WC3 patch).

## Removed

- Command history (it caused desyncs).
- `-setMonsterSpawnDirection` and `-setMonsterSpawnShape`, replaced by `-setMonsterSpawnZone`.
- The triple kill sound.

## MEC_core API

- `resetRoundScores()`: call it at the end of a cinematic so that the hero selection circles disappear again.
- `getMonstersAll()`, `getSpawnedMonstersAll()`: active monster units (spawned ones excluded / only spawned ones).
- `NewImmobileMonsterUnit()`, `NewPatrolMonsterUnit()`: create monster units.
- `json` library.
- New hooks: `onBeforeHeroUsingMeteor` (return `false` to cancel), `onGameWinning`.
- `MEC_core` is now a global variable.
